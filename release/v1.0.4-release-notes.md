`v1.0.4-showcase` is a presentation-focused patch of the public GymFlow engineering case study. It keeps the application snapshot and 53-image gallery from `v1.0.3-showcase` while refining how the project is introduced, explained, and navigated.

## Release improvements

- Reworked the README so the product, connected workflows, architecture, and engineering depth lead the presentation.
- Reframed the screenshot collection as a visual product tour while preserving its exact release record.
- Simplified source-access language and kept review permissions separate from licensing.
- Reframed the roadmap around product evolution and the path from showcase to commercial operation.
- Refined security, quality, engineering, and release language so technical boundaries remain clear without dominating the public narrative.
- Updated the walkthrough document to describe an optional future presentation format rather than an absent requirement.
- Kept release provenance, source revisions, gallery inventory, and validation tooling intact.

No application source revision or screenshot content changed in this patch.
