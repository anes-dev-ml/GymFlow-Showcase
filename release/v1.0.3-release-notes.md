# GymFlow `v1.0.3-showcase`

`v1.0.3-showcase` preserved a reviewed GymFlow application snapshot and complete visual gallery while refining the release record and validation tooling. It is the immutable release immediately preceding `v1.0.4-showcase`.

## Application snapshot

- Frontend: `b73a623c3985e4bc458d04b4b484887ada593fa5`
- Backend: `2234af20d1d9dd143bcac22edc699d3ee7fe515f`
- Alembic head: `9e4f6a8c2d1b`
- Demo workspace: Northline Performance Club
- Gallery: 53 screenshots across five galleries
- Previous release at the time: `v1.0.2-showcase` at `4e6f10276a5d17a51f7ddad12d9f909fd6f0fd7f`

## Release improvements

- Replaced the dynamic “latest immutable release” field with explicit current and previous release identities.
- Simplified record and release validation modes.
- Recorded exact SHA-256 values for the complete gallery.
- Added deterministic gallery-hash refresh tooling.
- Improved malformed-manifest handling and validator error messages.
- Expanded regression coverage for the complete repository gate.
- Strengthened local-link containment and release-integrity checks.

## Validation model

The release introduced the record/release validation flow used by later showcase patches:

```powershell
.\scripts\validate_release.ps1
.\scripts\validate_release.ps1 -Release
```

Equivalent POSIX commands:

```bash
bash scripts/validate_release.sh
bash scripts/validate_release.sh --release
```

## Included in the release

The release contains engineering documentation, architecture material, the deterministic-demo description, release records, and the reviewed visual gallery for the application snapshot above.

The frontend and backend implementations remain private. The public gallery uses fictional identities and demo/test payment states, with source review handled separately when appropriate.
