## Release improvements

- Replaced the dynamic “latest immutable release” field with explicit current and previous release identities.
- Simplified record and release validation modes.
- Recorded exact SHA-256 values for the complete gallery.
- Added deterministic gallery-hash refresh tooling.
- Improved malformed-manifest handling and validator error messages.
- Expanded regression coverage for the complete repository gate.
- Strengthened local-link containment and release-integrity checks.

## Validation

Record validation:

```powershell
.\scripts\validate_release.ps1
```

Release validation against a tag:

```powershell
.\scripts\validate_release.ps1 -Release
```

Equivalent POSIX commands:

```bash
bash scripts/validate_release.sh
bash scripts/validate_release.sh --release
```

The local gate covers validator tests, tracked-file hygiene, Markdown links, release records, source provenance, gallery hashes, rejected media, and tag alignment.

## Included in this release

The public release contains the engineering documentation, architecture material, deterministic-demo description, release records, and reviewed visual gallery for the snapshot above.

The frontend and backend implementations remain private. The public gallery uses fictional identities and demo/test payment states, and selected read-only source access may be considered separately for serious technical or recruitment review.

Provider configuration and commercial operation remain deployment-specific and are described in the [Roadmap](../ROADMAP.md).
