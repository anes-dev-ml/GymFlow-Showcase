# GymFlow `v1.0.3-showcase`

`v1.0.3-showcase` is the final public-release integrity correction for the GymFlow engineering case study.

It preserves the reviewed application snapshot and gallery while making the release model durable, exact, and unambiguous.

## Release improvements

- Replaced the dynamic “latest immutable release” field with explicit current and previous release identities.
- Removed pre-tag wording that became inaccurate after a release tag existed.
- Replaced candidate-oriented tooling with neutral record and release validation modes.
- Recorded 53 exact SHA-256 approvals for the 53 gallery images.
- Added deterministic evidence-hash refresh tooling.
- Made malformed nested manifest values produce clear validation errors instead of tracebacks.
- Expanded regression coverage to include the complete repository gate.
- Strengthened local-link containment and full evidence integrity checks.

## Validation

Record validation:

```powershell
.\scripts\validate_release.ps1
```

Release validation after tagging:

```powershell
.\scripts\validate_release.ps1 -Release
```

Equivalent POSIX commands:

```bash
bash scripts/validate_release.sh
bash scripts/validate_release.sh --release
```

The local gate validates unit tests, tracked-file hygiene, Markdown links, release truth, source provenance, all 53 exact SHA-256 approvals, rejected media, and tag alignment.

This release does not claim successful hosted CI. The reviewed local gate is the release authority.

## Evidence boundary

This release contains documentation and reviewed visual evidence. It does not include:

- private frontend or backend source code;
- production credentials or environment files;
- real client, staff, payment, or message data;
- an installable application binary;
- a current provenance-bound walkthrough video.

Provider-dependent production operation remains environment-specific.
