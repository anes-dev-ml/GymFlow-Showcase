# GymFlow `v1.0.2-showcase`

`v1.0.2-showcase` is a tag-bound release-integrity correction for the public GymFlow engineering case study.

It preserves the canonical application snapshots while strengthening how the repository records, validates, and presents its evidence. The same record remains accurate before tagging and becomes immutable when the tag points to the reviewed commit.

## Release improvements

- Corrected all documentation that still described `v1.0.1-showcase` as unreleased.
- Centralized release facts in `release/evidence-manifest.json`.
- Reworked validation to inspect tracked Git content.
- Added PowerShell and POSIX local release runners.
- Added validator regression tests.
- Strengthened cross-document source and release-state checks.
- Added evidence descriptions for every gallery image.
- Removed the unavailable and internally conflicting hosted workflow.
- Preserved exact approved hashes for high-risk evidence and blocked known rejected media.

## Validation

Record validation:

```powershell
.\scripts\validate_release.ps1
```

Release validation after tagging:

```powershell
.\scripts\validate_release.ps1 -Release
```

Equivalent POSIX commands:

```bash
bash scripts/validate_release.sh
bash scripts/validate_release.sh --release
```

This release does not claim successful hosted CI. The traditional local gate is the recorded release authority.

## Evidence boundary

This release contains documentation and reviewed visual evidence. It does not include:

- private frontend or backend source code;
- production credentials or environment files;
- real client, staff, payment, or message data;
- an installable application binary;
- a current provenance-bound walkthrough video.

Provider-dependent production operation remains environment-specific.
