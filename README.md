# GymFlow

GymFlow is a full-stack SaaS gym management platform built to demonstrate end-to-end software engineering across frontend, backend, authentication, payments, bookings, client portals, responsive UI, localization, and production-style architecture.

The source repositories are private because this is a complete product-style SaaS project. This showcase contains the product overview, architecture notes, screenshots, demo video, and demo build instructions.

## Status

GymFlow is feature-complete for showcase/demo purposes.

## Built with

- Flutter
- FastAPI
- PostgreSQL
- Alembic
- JWT authentication
- Google OAuth
- Stripe test payments
- Stripe Connect demo mode
- Responsive UI
- English, French, and Arabic localization
